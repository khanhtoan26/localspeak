## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser to same-origin `/api/*` rewrite | Browser calls API through Next rewrite instead of direct broad CORS. |
| API response to React UI | API status and contract validation JSON become visible text. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-01 | Information Disclosure | web env/source | mitigate | Frontend env may contain `API_INTERNAL_URL` only; grep blocks Gemini and Supabase secret exposure. |
| T-01-02 | Information Disclosure / Elevation of Privilege | web Supabase config | mitigate | Do not initialize Supabase or add secret keys in Phase 1 frontend. |
| T-01-03 | Tampering | fixture status UI | mitigate | Invalid contract status shows actionable error copy, not silent success. |
| T-01-04 | Information Disclosure | health status UI | mitigate | Render generic status/service only; no env names or secret values. |
| T-01-05 | Information Disclosure | local API access | mitigate | Use Next rewrite from `/api/:path*` to `http://localhost:3001`; frontend fetches same-origin paths. |
</threat_model>
