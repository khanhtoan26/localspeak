<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP client to Nest API | Untrusted local requests reach `/health` and `/contracts/sample-json/validate`. |
| Backend process to environment | Gemini and Supabase secret values enter trusted backend runtime. |
| Fixture file to API response | Vendor JSON is validated before endpoint output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-01 | Information Disclosure | API env config | mitigate | Keep `GEMINI_API_KEY` only in `apps/api`; never expose it in frontend files. |
| T-01-02 | Information Disclosure / Elevation of Privilege | Supabase config | mitigate | Keep `SUPABASE_SECRET_KEY` backend-only and never return it from endpoints. |
| T-01-03 | Tampering | `/contracts/sample-json/validate` | mitigate | Use `safeParse` and return structured Zod issues. |
| T-01-04 | Information Disclosure / DoS | `/health` | mitigate | Return generic status only; no env details or external dependency calls. |
| T-01-05 | Information Disclosure | CORS | mitigate | Prefer no broad CORS because Next rewrite handles local same-origin calls. |
</threat_model>
