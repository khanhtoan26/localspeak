<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client browser → app shell | page.tsx is "use client"; mode state is local React state, no server interaction |
| next/font → Google Fonts CDN | Font loading makes external request to fonts.googleapis.com during build/SSR |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Information Disclosure | Google Fonts request in next/font | accept | next/font self-hosts fonts by default at build time — fonts are downloaded and served from the Next.js app, not inline-fetched from Google at runtime. No user data is sent to Google Fonts CDN during browsing. |
| T-07-02-02 | Elevation of Privilege | Missing focus management on nav switch | mitigate | NavItem and BottomNavItem include `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:outline-none` — keyboard users get visible focus rings; Tab order preserved |
| T-07-02-03 | Denial of Service | Fixed bottom nav obscuring content at mobile | mitigate | Mobile main content has `pb-16` (64px bottom padding) to ensure content is never hidden beneath the fixed nav bar; safe-area-inset-bottom handles iOS notch |
| T-07-02-04 | Spoofing | aria-current="page" on both sidebar and bottom nav | accept | Both navs represent the same mode state; having aria-current on both is correct — screen readers should announce the current page in whichever nav is visible |
</threat_model>
