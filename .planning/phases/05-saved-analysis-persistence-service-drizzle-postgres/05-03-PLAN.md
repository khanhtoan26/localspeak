<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| controller/service input -> DB | Untrusted body/query/path values enter persistence code. |
| service -> Postgres | Persistence uses Drizzle query builder and DATABASE_URL-backed pg Pool. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-08 | Tampering | create/list/fetch inputs | mitigate | Validate all unknown input with Zod contracts before querying/inserting. |
| T-05-09 | Information Disclosure | fetch by id | mitigate | Always query with `id AND owner_key`; wrong owner returns 404. |
| T-05-10 | Denial of Service | JSONB payloads | mitigate | Enforce 2 MB service payload guard before validation/insert. |
| T-05-11 | Repudiation | DB failures | mitigate | Do not swallow DB errors or return fake success responses. |
| T-05-12 | SQL Injection | persistence queries | mitigate | Use Drizzle `eq`, `and`, `desc` query builder; no raw interpolated SQL. |
</threat_model>
