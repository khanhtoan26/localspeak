## Trust Boundaries

| Boundary | Description |
|---|---|
| developer CLI -> Drizzle Kit | Local migration commands must target explicit Postgres DATABASE_URL. |
| database schema -> future services | Service persistence relies on schema shape to protect owner scoping and raw-data minimization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-04 | Spoofing | `owner_key` | accept | `ownerKey` is partitioning only, not authentication; documented by context and contracts. |
| T-05-05 | Information Disclosure | JSONB columns | mitigate | Store derived `input_metadata`, `metrics`, and `feedback`; do not create raw vendor payload column. |
| T-05-06 | Denial of Service | missing DB config | mitigate | Drizzle config and DB helper throw explicit DATABASE_URL errors; no in-memory fallback. |
| T-05-07 | Tampering | migration generation | mitigate | Generated migration committed and checked with `drizzle-kit check`. |
</threat_model>
