# Phase 07.1 - Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest + Testing Library, Playwright, Next.js type/lint check |
| **Config file** | `apps/web/vitest.config.ts`, `apps/web/playwright.config.ts`, `apps/web/next.config.ts` |
| **Quick run command** | `pnpm --filter web check` |
| **Full suite command** | `pnpm --filter web check && pnpm --filter web test && pnpm --filter web test:e2e` |
| **Feedback latency target** | Targeted commands after each task; full suite after each wave |

---

## Sampling Rate

- **After every task commit:** Run `pnpm --filter web check` or a narrower targeted unit/E2E command named in the task.
- **After every plan wave:** Run `pnpm --filter web check && pnpm --filter web test && pnpm --filter web test:e2e`.
- **Before `/gsd-verify-work`:** Full suite must be green.
- **Max feedback latency:** No 3 consecutive tasks may rely only on manual inspection.
