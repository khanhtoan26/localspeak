<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> API analyze | User triggers backend metric computation through manual Analyze JSON only. |
| API analyze response -> React UI | Backend-derived metrics are parsed through shared schema before rendering. |
| Vendor text/paths -> DOM | Word text, IPA labels, paths, nearby words, and explanations render in React. |
| Result state -> learner interpretation | Deterministic metrics must not impersonate Gemini or an IELTS examiner. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-18 | Tampering | analyze contract parsing | mitigate | Parse with `JsonAnalysisResponseSchema`; malformed response shows safe error instead of success. |
| T-02-19 | Information Disclosure | full input echo | mitigate | UI uses derived fields only and tests do not require `speechAssessment` in success response. |
| T-02-20 | Elevation/XSS | result rows | mitigate | React text-node rendering only; no `dangerouslySetInnerHTML`; tests include script-like word text. |
| T-02-21 | Spoofing | deterministic tone | mitigate | Copy says `This suggests...` and forbids Gemini/examiner claims; tests assert forbidden strings absent. |
| T-02-22 | Tampering | stale preview/analyze drift | mitigate | Manual analyze uses current textarea JSON; input changes after success mark results stale. |
| T-02-23 | Information Disclosure | third-party/Gemini sharing | mitigate | Fetch only same-origin `/api/json-analysis/analyze`; no Gemini/Supabase/audio/history code. |
</threat_model>
