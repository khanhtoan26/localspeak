<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| User/file system -> browser textarea | Untrusted pasted or uploaded text enters React state. |
| Browser -> API preview | Parsed JSON is sent to backend validation preview only after syntax parse. |
| API preview response -> React UI | Backend validation data is parsed with shared schemas before rendering. |
| Vendor text -> DOM | Vendor strings may contain HTML/script-like content and must render as text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-12 | Denial of Service | upload/input UI | mitigate | Enforce 2 MB file limit before File.text(); display exact friendly over-limit copy. |
| T-02-13 | Tampering | preview vs analyze state | mitigate | Analyze button depends on latest backend preview; input changes mark results stale and require re-analysis. |
| T-02-14 | Information Disclosure | technical details UI | mitigate | Details collapsed by default and populated only from safe parsed preview fields. |
| T-02-15 | Information Disclosure | third-party/Gemini boundary | mitigate | Fetch only same-origin `/api/json-analysis/*`; no Gemini/Supabase/analytics/audio code. |
| T-02-16 | Elevation/XSS | vendor text rendering | mitigate | Render all strings as React text nodes; prohibit `dangerouslySetInnerHTML`; component tests include script-like text. |
| T-02-17 | Spoofing | backend contract bypass | mitigate | Parse sample and preview responses with shared Zod schemas before success UI. |
</threat_model>
