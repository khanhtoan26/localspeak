# Sketch 001: Premium Coach Dashboard

## Design Question

Which full-screen structure makes the next practice action feel premium, confident, and obvious while still preserving access to JSON analysis and live audio practice?

## How to View

Open `.planning/sketches/001-premium-coach-dashboard/index.html`.

## Variants

- **A: Coach Command Center** - Winner. A premium dashboard with a dark rail, a large next-practice hero, and supporting evidence cards.
- **B: Superhuman Split** - A productivity-style split view where sessions, insight, and next drill are visible at once.
- **C: Focus Sprint** - A single-task coaching view that strips the page down to one high-leverage drill.

## What to Look For

Compare which structure makes the product feel least like a generic dashboard and most like a confident learning coach. Pay attention to first-glance clarity, perceived polish, and whether the details support or distract from the next practice action.
