# Sketch 002: Analysis to Practice Flow

## Design Question

How should LocalSpeak turn JSON analysis results into a concrete practice loop so the user feels coached rather than merely diagnosed?

## How to View

Open `.planning/sketches/002-analysis-to-practice-flow/index.html`.

## Variants

- **A: Next Drill Hero** - Winner. Results collapse into a single drill card with clear start, timer, and replay loop.
- **B: Coach Plan Timeline** - A structured practice plan with expandable steps and evidence for each step.
- **C: Score-to-Action Map** - Metrics remain visible, but every score is mapped to an action and queue.

## What to Look For

Compare which flow best converts analysis into action without overwhelming the learner. Pay attention to motivation, clarity, and whether the UI naturally leads to recording or repeating practice.
