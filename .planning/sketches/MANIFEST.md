# Sketch Manifest

## Design Direction

LocalSpeak should feel like a premium learning coach: calm, polished, focused, and sharper than the current plain dashboard. The primary screen should make the next best pronunciation practice action immediately obvious after analysis, with the analysis details supporting that action instead of competing with it.

## Reference Points

Linear and Superhuman: crisp structure, premium density, strong hierarchy, deliberate micro-interactions, and minimal visual noise.
